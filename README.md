# 女性高管认知烙印对企业绿色创新的影响研究

第十组第5次课堂报告的静态演示。十六幕内容与幻灯片原文一致，用浏览器打开即可，不需要安装依赖，也不需要构建。

## 本地打开

在本目录启动一个静态服务器：

```bash
python3 -m http.server 8741
```

然后在浏览器访问 <http://127.0.0.1:8741/> 。

也可以直接双击 `index.html`。若三维背景没有出现，请改用上面的本地服务器。

## 课堂操作

- 打开后先播放一段开场，再进入封面。按任意键、点击画面或「跳过开场」可提前进入封面。
- 方向键、空格、PageUp / PageDown 前后翻页；Home / End 到首尾。
- 点击画面右侧进入下一幕，左侧返回；也可以滑动，或点底部进度。
- 按 F 或右上角「全屏」，适合投屏。
- 地址栏加上 `?direct=10` 可跳过开场，直接打开第 10 幕。

## 放到 GitHub Pages

本目录就是站点根目录，已包含 `.nojekyll`。在仓库设置中把 Pages 的来源选为所在分支的根目录即可。页面只使用相对路径。
