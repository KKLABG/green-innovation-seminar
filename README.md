# 女性高管认知烙印对企业绿色创新的影响研究

第十组第5次课堂报告。十六幕正文与幻灯片原文一致，页面由代码排版。每一幕换一个浅色林地里的场所，镜头也不只朝前走。课堂插图放在版式一侧或横幅中，用来增加人物气息。

## 本地打开

```bash
python3 -m http.server 8741
```

浏览器访问 <http://127.0.0.1:8741/> 。请用本地服务器打开，这样三维画面和字体才能稳定加载。

## 课堂操作

- 开场动画结束后进入封面。点击画面、按任意方向键或空格，或点「跳过开场」，可提前进入封面。
- 方向键、空格、PageUp / PageDown 前后翻页；Home / End 到首尾。
- 底部圆点与「上一幕 / 下一幕」可点击。画面右侧空白处也可进入下一幕。
- 不会自动翻页。
- 右上角「全屏」适合投屏。地址栏加上 `?at=10` 可跳过开场，直接打开第 10 幕。
